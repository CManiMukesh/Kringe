# Kringe - Anonymous Text Feed

A minimalist, anonymous, text-only social media web application built with the MERN stack.

## Features

- **Zero authentication** - No signup, no login, no tracking
- **Fullscreen swipeable feed** - One post at a time, TikTok-style vertical scrolling
- **Anonymous posting** - Randomly generated labels per post (no persistent identities)
- **180 character limit** - Short, raw, chaotic thoughts only
- **Spam protection** - Rate limiting, profanity filtering, duplicate content detection
- **Mobile-first design** - Optimized for thumb scrolling

## Tech Stack

- **Frontend**: React + Vite, plain CSS, React Router
- **Backend**: Node.js + Express.js
- **Database**: MongoDB Atlas (Mongoose ODM)
